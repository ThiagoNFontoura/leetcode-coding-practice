Soluções de problemas do LeetCode, resolvidas em C++, organizadas por ID e nome do problema. Treino diário para entrevistas técnicas.

Estrutura

Cada problema tem sua própria pasta, nomeada como ID-nome-do-problema, com o ID em 4 dígitos pra manter a ordenação correta. Exemplo: 0001-two-sum.

Dentro de cada pasta:

solution.cpp - a solução em C++
notes.txt - anotações sobre o padrão usado (Hash Map, Two Pointers, DP, Sliding Window etc), complexidade de tempo e espaço, e observações sobre a primeira tentativa
